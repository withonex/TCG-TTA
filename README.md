# SAFE

**SAFE: A Stream-Aware Forward-Only Ensemble for Test-Time Adaptation in EEG-Based Brain-Computer Interfaces**

> [!IMPORTANT]
> **Release status:** This repository is an early public preview. The complete SAFE source code, experiment configurations, and reproducibility instructions will be made publicly available after the paper is accepted.

SAFE is a streaming test-time adaptation framework for EEG-based brain-computer interfaces. It performs test-time inference without backpropagation while keeping the source model parameters frozen.

## Repository status

The current preview intentionally contains only non-core documentation and repository scaffolding. The method implementation, training and evaluation pipelines, experiment configurations, checkpoints, and result artifacts are not part of this preview.

The full release is planned to include:

- the complete SAFE implementation;
- training and evaluation entry points;
- fixed experiment configurations;
- environment and dependency setup;
- data preparation and organization instructions; and
- scripts for reproducing and summarizing the reported experiments.

See [Release status](docs/RELEASE_STATUS.md) for details.
