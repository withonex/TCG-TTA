# Release status

## Current stage

This repository is a public preview for the SAFE paper. It currently contains non-core project documentation only and is not yet a reproducibility release.

The complete SAFE source code will be released after the paper is accepted.

## Planned full release

The post-acceptance release is planned to provide:

- the SAFE method implementation;
- training, validation, and evaluation scripts;
- fixed configurations for the reported experiments;
- dependency and environment specifications;
- dataset preparation and directory-layout instructions; and
- result aggregation and visualization utilities.

Datasets and third-party assets will remain subject to their original licenses. When redistribution is not permitted, the repository will provide links to the official sources and instructions for preparing the required files locally.

## Versioning

The first complete code release will be tagged so that the paper-facing implementation can be referenced reproducibly.
